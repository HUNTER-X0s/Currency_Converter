# 💱 Currency Converter

A simple and responsive **Currency Converter Web Application** that converts one currency to another using real-time exchange rates.

---

## 🚀 Features

* 🌍 Convert between multiple international currencies
* ⚡ Real-time exchange rates
* 📱 Fully responsive (mobile & desktop)
* 🎯 Simple and clean user interface
* 🧠 Beginner-friendly JavaScript logic

---

## 🛠️ Technologies Used

* **HTML5** – Structure of the web page
* **CSS3** – Styling and responsiveness
* **JavaScript (ES6)** – Logic and API handling

---

## 📂 Project Structure

```
Currency_Converter/
│
├── index.html      # Main HTML file
├── style.css       # Styling
├── app.js          # Main JavaScript logic
├── code.js         # Helper / API logic
├── old_app.js      # Older version (optional)
└── README.md       # Project documentation
```

---

## ⚙️ How to Run Locally

1. Clone the repository

   ```bash
   git clone https://github.com/HUNTER-X0s/Currency_Converter.git
   ```

2. Open the project folder

   ```bash
   cd Currency_Converter
   ```

3. Open `index.html` in your browser

   > No server required
